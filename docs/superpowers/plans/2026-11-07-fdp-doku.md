# FDP-Doku „Der Fall der FDP“ – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aus der AfD-Doku-Pipeline einen ~25-min-Film „Der Fall der FDP“ im Stil der Stilstudie bauen, mit Gemini-Erzählstimme, neuen Grafikmodulen und Blender-Nachstellungen auf RunPod.

**Architecture:** Das neue Repo `fdp-doku` entsteht als Kopie von `afd-doku` (Python, `ton/` + `schnitt/`). Für die Stimme kommt `ton/gemini.py` hinzu. `ton/erzaehler.py` wählt den Anbieter aus dem Drehbuch-Feld `stimme.anbieter`. Neue Grafik-Elemente sind wie bisher Funktionen `(parameter, dauer) -> Clip` und werden in `schnitt/grafik/drehbuch.clip_aus_eintrag` registriert. Nachstellungen sind Blender-Szenen, die über das bestehende `wolke_film`/`pod_film.sh` gerendert werden.

**Tech Stack:** Python 3, requests, Pillow, numpy, ffmpeg, faster-whisper, Blender 5.2 (EEVEE), RunPod, Gemini API (`gemini-3.8-flash-tts`), ElevenLabs Music.

**Spec:** `~/Documents/Programmierung/flexibilizar-brand/docs/superpowers/specs/2026-11-07-fdp-doku-design.md`

## Global Constraints
- Repo `supertony0403/fdp-doku`, **privat**. Daten unter `/mnt/steam-library/fdp-doku/`, nie in `/tmp` (tmpfs).
- Farben: `TINTE #1e1a16`, `ELFENBEIN #eee6d6`, Signal **`BERNSTEIN #E4922A`**, `MARKER #f7d63e` nur als Textleuchtstift und Ident. **Kein Rot, kein Blau**, kein großflächiges Gelb.
- 1920×1080, 24 fps. Ziel 25:00 (erlaubt 22–28 min). Master −14 LUFS.
- Stimme: `gemini-3.8-flash-tts`, Schlüssel nur aus `~/.config/ddr-video/gemini.env` (Variable `GEMINI_API_KEY`). Schlüssel nie ausgeben oder loggen. Fehlertexte enthalten nur Statuscode und API-Fehlergrund.
- Stil-Prompt für alle Erzähltakte: „ernst, nah am Mikrofon, ruhig, leicht gespannt, Dokumentarfilm, deutsches Hochdeutsch“. Tempo-Ziel 135 Wörter/min.
- Neutralität: Regeln aus `afd-doku/docs/konzept.md` plus Abschnitt 4/4a der Spec. Jede Tatsache mit `beleg`. Vor dem Rendern null offene `pruefen`-Felder.
- Erlaubte Quellen: Bundestag-Mediathek (keine Grafik auf dem Clip, „live“-Uhr abgeschnitten), Wikimedia Commons mit Lizenz, kurze Zitate mit Quelle. **Keine TV-, Talkshow- oder Parteikanal-Videos.**
- Nachstellungen: gesichtslose, stilisierte Figuren, keine Abbilder realer Personen, keine erfundenen Dialoge, Einblendung „Nachstellung“.
- RunPod-Budget gesamt **5,00 $**, harter Abbruch darüber. Pods ohne SSH-Port nach 5 min ersetzen.
- Lokale Läufe als `systemd-run --user --unit=… -p CPUWeight=1 -p CPUQuota=100% -p AllowedCPUs=10-11 -p MemoryMax=4G nice -n 19 ionice -c3`, keine lokale GPU.
- Nichts hochladen. Nach jeder Aufgabe committen und pushen. Pflicht-Review durch `senior-code-reviewer` nach den Code-Aufgaben 2, 5, 6 und 7.

## Review Focus
1. Gemini liefert 200 ohne Audio, blockiert aus Sicherheitsgründen oder schneidet das Audio ab. Erwartet: Der Versuch gilt als fehlgeschlagen (Whisper-Quote unter Schwelle oder Dauer zu kurz) und wird neu geholt, nie still übernommen → Test in Aufgabe 2.
2. Das Tageskontingent ist mitten im Lauf erschöpft (429 mit Quota-Grund). Erwartet: sauberer Halt mit `GeminiKontingent`, fertige Takte bleiben im Cache, der nächste Lauf macht dort weiter → Test in Aufgabe 2.
3. Zahlen und Namen werden falsch gesprochen („4,3 Prozent“, „Djir-Sarai“, „D-Day“). Erwartet: `sprechtext` schreibt Zahlen aus, die Eigennamenprüfung meldet Abweichungen → Test in Aufgabe 2.
4. Ein Grafikmodul verdeckt die Quellenzeile, ein Fehler der AfD-Doku. Erwartet: Die Prüfung schlägt fehl → Test in Aufgabe 6.
5. Ein Bundestag-Clip zeigt die Original-„live“-Uhr. Erwartet: Der Clip ist beschnitten oder sitzt im TV-Rahmen, die Prüfung erkennt den Bereich → Test in Aufgabe 6.
